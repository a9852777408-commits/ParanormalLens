# Руководство: Как добавлять новых сущностей после публикации ParanormalLens

Данный документ описывает регламент расширения бестиария как без обновления приложения (по воздуху), так и через плановые обновления в магазинах.

---

## 🚀 Способ 1. Мгновенно «По воздуху» (Over-The-Air) без модерации сторов

Используется для сезонных ивентов (Хэллоуин, Пятница 13-е), добавления призраков для новых городов и балансировки игры.

### Инструкция:
1. Откройте в браузере ваш публичный репозиторий контента (на GitHub или Cloudflare R2).
2. Найдите файл `entities_catalog.json`.
3. Нажмите кнопку **Редактировать** ✏️.
4. Добавьте новую сущность по шаблону:

```json
{
  "id": "new_entity_unique_id",
  "name": "Название сущности (напр. Призрак Белой Башни)",
  "region_target": "cis_slavic_profile", // mena_islamic_profile / western_gothic_profile / cis_slavic_profile
  "archetype_id": 0,                      // 0: Slender, 1: Lurker, 2: Mist, 3: Flying Head, 4: White Cemetery, 5: Inverted Raven
  "rarity": "rare",                      // common, uncommon, rare, very_rare, mythic
  "behavior_description": "Краткое описание поведения на экране",
  "lore_text": "Историческая справка для карточки в Бестиарии",
  "location_lock": {
    "enabled": false,                    // true, если привязан к GPS
    "latitude": 59.9405,
    "longitude": 30.3378,
    "radius_meters": 300
  }
}
```
5. Нажмите **Commit changes** (Сохранить).
6. **Готово**: При следующем открытии приложения у всех пользователей загрузится свежий каталог. Прогресс старых игроков не затрагивается.

---

## 🛠 Способ 2. Через обновление версии в магазинах (App Store / Google Play / RuStore)

Используется, когда добавляется **принципиально новая графика (новый шейдер)** или программная механика.

### Пошаговый процесс:
1. **Добавление в код**:
   * Отредактируйте `lib/core/models/regional_profile.dart`, добавив запись в `spawnPool`.
   * Если нужен новый силуэт — добавьте математическую формулу SDF в `shaders/procedural_shadow.frag` с новым номером `uArchetype`.
2. **Инкремент версии**:
   * В `pubspec.yaml` увеличьте версию:
     ```yaml
     version: 1.1.0+2  # было 1.0.0+1
     ```
3. **Сборка бинарников**:
   * Для Google Play: `flutter build appbundle`
   * Для RuStore: `flutter build apk --release`
   * Для App Store: `flutter build ipa`
4. **Загрузка в консоли**: Загрузите файлы в Google Play Console, RuStore Консоль и App Store Connect.
